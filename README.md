# Pieced

Pieced is a solo first-person shooter with Fortnite-style building. You fight with a pump and a SCAR, and throw up walls, ramps and floors in a chunky low-poly world. It's built in Rust with Bevy for one MacBook Air, played with WASD and the trackpad.

**Status:** Milestone 1, "Sparring", is being built. It's a feel test: movement, both guns, grid building and a strafing training dummy, running at a steady 60 fps on battery. Bots come in Milestone 2.

## Build and run

This needs Apple Silicon macOS and the workspace-local Rust 1.98.1 toolchain.

```sh
source scripts/env.sh
cargo run --release
```

## Controls (Milestone 1)

| Input | Action |
|---|---|
| WASD / trackpad | Move / look |
| Trackpad click | Fire, or place piece (hold for full-auto or turbo build) |
| Two-finger click or V | Toggle aim-down-sights |
| Space / Shift / C | Jump / sprint / crouch (slide while sprinting) |
| 1 / 2 | SCAR / pump |
| Q / E / F | Wall / ramp / floor |
| R | Reload |
| Esc / F3 / F4 | Pause / performance overlay / tuning panel |

All meshes, sounds and palettes are original and generated by the project's own code.
